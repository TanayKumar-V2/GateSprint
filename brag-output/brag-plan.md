# Brag Plan: GATE Mentor

## What is this app?
GATE Mentor is a focused GATE CS/IT prep workspace: practice real previous-year questions by subject/topic/year/difficulty, get server-validated results instantly, and ask an AI Mentor that explains every miss step by step with your full attempt context attached.

## The angle
A tactical field-manual product film. No hype, no gamified noise — just the loop that actually cracks GATE: attempt with intent, understand every miss, retain what matters. The video looks like the site feels: black CRT command deck, mono telemetry, red action bars, hazard stripes. Calm, precise, confident.

## Hook (first 2-3 seconds)
Full-screen black. Scanlines on. One line slams in at full scale:
"STOP GUESSING."
Hold. Then red "START KNOWING." underneath. This is the site's own final transmission — the strongest 4 words it owns — and it earns the next 17 seconds instantly.

## Key moments (the middle)
- The hero command deck recreated: "MAKE EVERY QUESTION COUNT®" with the telemetry strip (EXAM / MODE / BANK / LINK ● LIVE).
- The protocol loop as a 3-step working-app demo: ATTEMPT a timed PYQ → MISS dissected by Mentor with pick + solution context → RETAIN via bookmarks + weak-topic progress.
- The signal table: OPERATING SYSTEMS / ALGORITHMS / DATABASES rows with PYQ counts — proof this is a real bank, not a chatbot wrapper.

## Outro / punchline
"GATE MENTOR® /// FIELD MANUAL REV 2.6" + "083+ PYQ UNITS. 08 SUBJECTS. 01 MENTOR." then CTA: "OPEN THE QUESTION BANK +". Lands on confidence, not a joke.

## User flow worth showing
Entry → key action → result, from Journeys A/B/D:
- Entry: open Practice, filter by subject/topic/year/difficulty (Operating Systems, 2023, MCQ).
- Key action: select an answer, submit, see Correct/Incorrect + marks instantly; click ASK MENTOR — session opens with question + pick + correct answer + solution pre-attached.
- Result: Mentor explains the trap step by step; Progress shows accuracy + weak topics; bookmark queues the question for revision.
